# Hi, I'm Matthew Pitts

I build desktop apps, websites, Cloudflare Workers back ends and scalable enterprise applications.
I run Ravenburst, and I made Perchlight.

## Projects

- **[Ravenburst](https://ravenburst.com)**: a distraction-free desktop writing app for novelists, screenwriters and playwrights (Windows, macOS, Linux).
- **[Perchlight](https://github.com/matpitts13/perchlight)**: a free desktop app (Windows, macOS, Linux) for managing Cloudflare Workers KV and D1, with a no-code screen builder. [Website](https://perchlight.ravenburst.com)
- **[perchlight-list](https://github.com/matpitts13/perchlight-list)**: a free, self-hosted mailing list on Cloudflare Workers + D1, with announcements through Resend, Amazon SES, Mailgun or Postmark.
- **[perchlight-updates](https://github.com/matpitts13/perchlight-updates)**: a free, self-hosted update server for Electron and Tauri apps on Cloudflare: release channels, gradual rollouts, pulling a bad release, private beta feeds and download counts.
- **[perchlight-guard](https://github.com/matpitts13/perchlight-guard)**: a free, self-hosted Cloudflare Worker that warns you by email or webhook at 80% and 100% of every Cloudflare free-plan limit, and of GitHub Actions' free allowance.
- **[perchlight-crashes](https://github.com/matpitts13/perchlight-crashes)**: free, self-hosted crash and error reports for desktop apps and games on Cloudflare; Electron's crash reporter and Sentry SDKs send to it unchanged.
- **[perchlight-forms](https://github.com/matpitts13/perchlight-forms)**: a free, self-hosted backend for website forms on Cloudflare, with spam filtering, file uploads and email or webhook alerts.
- **[perchlight-booking](https://github.com/matpitts13/perchlight-booking)**: a free, self-hosted booking page on Cloudflare that reads busy times from your own calendar, never double-books, and sends calendar invites.
- **[perchlight-status](https://github.com/matpitts13/perchlight-status)**: free, self-hosted uptime checks, a public status page, and domain and certificate expiry warnings on Cloudflare.
- **[perchlight-hooks](https://github.com/matpitts13/perchlight-hooks)**: a free, self-hosted webhook inspector, scheduled jobs and heartbeat monitors on Cloudflare.
- **[perchlight-play](https://github.com/matpitts13/perchlight-play)**: free, self-hosted leaderboards, cloud saves and remote config for games.
- **[perchlight-privacy](https://github.com/matpitts13/perchlight-privacy)**: a free, self-hosted privacy checker for your own websites.
- **[perchlight-keys](https://github.com/matpitts13/perchlight-keys)**: free, self-hosted software license keys with offline checks.
- **[perchlight-ask](https://github.com/matpitts13/perchlight-ask)**: a free, self-hosted ask-the-docs widget and AI support inbox drafts.
- **[perchlight-beta](https://github.com/matpitts13/perchlight-beta)**: a free, self-hosted private beta and advance-reader portal.
